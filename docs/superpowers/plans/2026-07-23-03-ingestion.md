# Link Ingestion Implementation Plan (Plan 3 of 4)

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Paste a link — a Twitter/X post, a YouTube or TikTok video, a Medal clip, a Discord CDN attachment, or a plain image URL — and have it land in the library as one or more items, fetched safely, with failures reported in language a friend can act on.

**Architecture:** `internal/ingest` acquires *bytes from the internet* and hands each resulting file to Plan 2's `media.Store.Save` with `SourceURL` and `JobID` set. It never writes to `files/`, never hashes, never touches the allowlist — one ingestion pipeline, reached two ways. A URL is classified into one of four kinds, then either fetched over a hardened HTTP client (SSRF-guarded at the socket, not just at the hostname) or ripped with `yt-dlp`, with `gallery-dl` as the Twitter-gallery fallback. Everything runs inside the `ingest_url` handler registered on Plan 2's queue, so retries, backoff and error surfacing come for free.

**Tech Stack:** Everything from Plans 1–2, plus `yt-dlp` and `gallery-dl` (both soft dependencies). No new Go module dependencies — `net/netip`, `net.Dialer.Control` and `syscall.Statfs` are stdlib.

## Global Constraints

Plans 1 and 2's Global Constraints hold in full. These add to them.

- **All acquired bytes go through `media.Store.Save`.** `internal/ingest` never writes to `files/`, never hashes, never decides a mime type. The served-mime allowlist, the webp policy and dedup are Plan 2's job and must not be duplicated here.
- **SSRF guard is enforced at the socket via `net.Dialer.Control`**, which inspects the *resolved* IP immediately before connect. Hostname pre-resolution alone is insufficient — it loses to DNS rebinding. `CheckRedirect` additionally re-validates scheme and hop count. Verified: a `Control` rejection propagates out of `http.Client.Get` as a wrapped error.
- **Blocked address ranges:** loopback, unspecified, link-local (unicast and multicast), multicast, and explicitly `0.0.0.0/8`, `10.0.0.0/8`, `100.64.0.0/10` (CGNAT), `127.0.0.0/8`, `169.254.0.0/16`, `172.16.0.0/12`, `192.0.0.0/24`, `192.168.0.0/16`, `198.18.0.0/15`, `224.0.0.0/4`, `240.0.0.0/4`, `::1/128`, `fc00::/7`, `fe80::/10`, `ff00::/8`, `64:ff9b::/96`. IPv4-mapped IPv6 is unmapped before checking.
- **`http` and `https` only.** Every other scheme is rejected at classification: `file:`, `ftp:`, `data:`, `gopher:`, `javascript:` and friends never reach a dialer.
- **Redirects capped at 5 hops**, each re-validated.
- **Download size is capped three ways:** a `Content-Length` precheck, an `io.LimitReader` at the cap (the precheck is a courtesy, the limited reader is the enforcement), and `--max-filesize` for yt-dlp. The cap comes from the `download_max_bytes` setting.
- **Free-disk precheck before every acquisition.** A home server that fills its disk mid-download corrupts nothing but confuses everyone.
- **External tools are argv arrays, never shell strings**, and always take `--` before the URL so a URL beginning with `-` cannot become a flag.
- **`yt-dlp` and `gallery-dl` are soft dependencies.** Missing tools fail the *job* with an actionable message; they never stop the server.
- **No test may reach the network.** Fixture servers are `httptest`; external tools are stubbed with Plan 2's `media.StubTools`.
- **TDD throughout**; commit at the end of every task.

```go
// Package ingest acquires media from the internet — guarded HTTP fetches and
// yt-dlp/gallery-dl rips — and hands every resulting file to
// media.Store.Save. It never writes into files/, never hashes, and never
// decides a mime type: that is the media package's job, and having exactly one
// implementation of it is the point.
package ingest

import (
	"errors"
	"fmt"
	"net/url"
	"strings"
)

// ErrUnsupportedSource means the URL can never be fetched safely.
var ErrUnsupportedSource = errors.New("ingest: unsupported source")

// SourceKind is how a URL will be acquired.
type SourceKind int

const (
	KindUnsupported SourceKind = iota
	KindDirect
	KindDiscordCDN
	KindYtDlp
)

func (k SourceKind) String() string {
	switch k {
	case KindDirect:
		return "direct"
	case KindDiscordCDN:
		return "discord-cdn"
	case KindYtDlp:
		return "yt-dlp"
	default:
		return "unsupported"
	}
}

// Extractors are the yt-dlp sources supported at launch. The names double as
// the suffix of the per-extractor cookie settings key and the basename of the
// cookie file in data/cookies.
var Extractors = []string{"twitter", "youtube", "tiktok", "medal"}

// DiscordCDNHosts are fetched directly and immediately: the URLs are signed
// and expire, so queueing them behind a slow yt-dlp run loses the content.
var DiscordCDNHosts = []string{"cdn.discordapp.com", "media.discordapp.net"}

// extractorHosts maps an exact hostname to its extractor. Matching is exact,
// with a separate suffix rule for subdomains, so "youtube.com.evil.test"
// cannot impersonate youtube.
var extractorHosts = map[string]string{
	"twitter.com":   "twitter",
	"x.com":         "twitter",
	"youtube.com":   "youtube",
	"youtu.be":      "youtube",
	"tiktok.com":    "tiktok",
	"medal.tv":      "medal",
}

// Classification is the result of inspecting a pasted URL.
type Classification struct {
	Kind      SourceKind
	Extractor string // "" unless Kind is KindYtDlp
	URL       string // trimmed, fragment removed
}

// Classify decides how a pasted URL will be acquired.
//
// An unknown host is KindDirect rather than KindUnsupported: pasting a plain
// image link from an arbitrary site is a core use case, and the served-mime
// allowlist already rejects anything that turns out not to be media.
// KindUnsupported is reserved for URLs that could never be fetched safely.
func Classify(raw string) (Classification, error) {
	trimmed := strings.TrimSpace(raw)
	if trimmed == "" {
		return Classification{}, fmt.Errorf("%w: no URL given", ErrUnsupportedSource)
	}

	parsed, err := url.Parse(trimmed)
	if err != nil {
		return Classification{}, fmt.Errorf("%w: %q is not a valid URL", ErrUnsupportedSource, trimmed)
	}
	switch strings.ToLower(parsed.Scheme) {
	case "http", "https":
	default:
		return Classification{}, fmt.Errorf("%w: only http and https links can be ingested, got %q",
			ErrUnsupportedSource, parsed.Scheme)
	}

	host := strings.ToLower(parsed.Hostname())
	if host == "" {
		return Classification{}, fmt.Errorf("%w: %q has no host", ErrUnsupportedSource, trimmed)
	}

	// A fragment is never transmitted and only confuses external tools.
	parsed.Fragment = ""
	normalized := parsed.String()

	for _, cdn := range DiscordCDNHosts {
		if hostMatches(host, cdn) {
			return Classification{Kind: KindDiscordCDN, URL: normalized}, nil
		}
	}
	if extractor, ok := lookupExtractor(host); ok {
		return Classification{Kind: KindYtDlp, Extractor: extractor, URL: normalized}, nil
	}
	return Classification{Kind: KindDirect, URL: normalized}, nil
}

// lookupExtractor resolves a hostname to a yt-dlp extractor, allowing
// subdomains such as www., m., mobile. and vm.
func lookupExtractor(host string) (string, bool) {
	for candidate, extractor := range extractorHosts {
		if hostMatches(host, candidate) {
			return extractor, true
		}
	}
	return "", false
}

// hostMatches reports whether host is exactly want or a subdomain of it.
// Plain strings.Contains or HasSuffix without the dot would let
// "youtube.com.evil.test" and "notyoutube.com" through.
func hostMatches(host, want string) bool {
	return host == want || strings.HasSuffix(host, "."+want)
}
```

```go
package ingest

import (
	"errors"
	"fmt"
	"net"
	"net/netip"
)

// ErrBlockedAddress means a connection was refused because the resolved
// address is inside the private, loopback, link-local or otherwise reserved
// space. On a home server this is the difference between "fetch a meme" and
// "let a friend's leaked API key probe the router admin page".
var ErrBlockedAddress = errors.New("ingest: refusing to connect to a private or reserved address")

// BlockedPrefixes are refused outright. The stdlib Addr predicates cover most
// of this, but not CGNAT (100.64/10) or the IETF assignment and benchmarking
// ranges, so they are listed explicitly.
var BlockedPrefixes = []netip.Prefix{
	netip.MustParsePrefix("0.0.0.0/8"),          // "this network"
	netip.MustParsePrefix("10.0.0.0/8"),         // RFC1918
	netip.MustParsePrefix("100.64.0.0/10"),      // CGNAT
	netip.MustParsePrefix("127.0.0.0/8"),        // loopback
	netip.MustParsePrefix("169.254.0.0/16"),     // link-local, incl. cloud metadata
	netip.MustParsePrefix("172.16.0.0/12"),      // RFC1918
	netip.MustParsePrefix("192.0.0.0/24"),       // IETF protocol assignments
	netip.MustParsePrefix("192.168.0.0/16"),     // RFC1918
	netip.MustParsePrefix("198.18.0.0/15"),      // benchmarking
	netip.MustParsePrefix("224.0.0.0/4"),        // multicast
	netip.MustParsePrefix("240.0.0.0/4"),        // reserved, incl. 255.255.255.255
	netip.MustParsePrefix("::1/128"),            // IPv6 loopback
	netip.MustParsePrefix("::/128"),             // IPv6 unspecified
	netip.MustParsePrefix("fc00::/7"),           // IPv6 unique local
	netip.MustParsePrefix("fe80::/10"),          // IPv6 link-local
	netip.MustParsePrefix("ff00::/8"),           // IPv6 multicast
	netip.MustParsePrefix("64:ff9b::/96"),       // NAT64: wraps IPv4, including private space
}

// IsBlockedAddr reports whether an address must not be connected to.
// Anything invalid is blocked: the safe default is refusal.
func IsBlockedAddr(addr netip.Addr) bool {
	if !addr.IsValid() {
		return true
	}
	// An IPv4-mapped IPv6 address must be judged as the IPv4 address it is,
	// or ::ffff:127.0.0.1 would sail straight past every IPv4 prefix.
	addr = addr.Unmap()

	if addr.IsLoopback() || addr.IsUnspecified() ||
		addr.IsLinkLocalUnicast() || addr.IsLinkLocalMulticast() ||
		addr.IsInterfaceLocalMulticast() || addr.IsMulticast() {
		return true
	}
	for _, prefix := range BlockedPrefixes {
		// Compare only within the same family; a v4 prefix never contains a
		// v6 address and Contains would simply return false, but checking
		// makes the intent explicit.
		if prefix.Addr().Is4() == addr.Is4() && prefix.Contains(addr) {
			return true
		}
	}
	return false
}

// CheckDialAddress validates a "host:port" as handed to net.Dialer.Control.
// By that point the host is always a literal IP; a hostname would mean
// resolution has not happened and nothing can be trusted.
func CheckDialAddress(address string) error {
	host, _, err := net.SplitHostPort(address)
	if err != nil {
		return fmt.Errorf("ingest: cannot parse dial address %q: %w", address, err)
	}
	addr, err := netip.ParseAddr(host)
	if err != nil {
		return fmt.Errorf("ingest: dial address %q is not a resolved IP", address)
	}
	if IsBlockedAddr(addr) {
		return fmt.Errorf("%w: %s", ErrBlockedAddress, addr)
	}
	return nil
}
```

```go
package ingest

import (
	"errors"
	"fmt"
	"net"
	"net/http"
	"net/netip"
	"strings"
	"syscall"
	"time"
)

// ErrTooManyRedirects means the redirect cap was hit.
var ErrTooManyRedirects = errors.New("ingest: too many redirects")

// Fetch defaults.
const (
	DefaultMaxRedirects = 5
	DefaultFetchTimeout = 5 * time.Minute
)

// ClientOptions configures the guarded HTTP client.
type ClientOptions struct {
	MaxRedirects int
	Timeout      time.Duration

	// AllowPrivateAddressesForTests disables the address policy entirely.
	// It exists because httptest servers live on loopback. Never set it in
	// production code: it removes the SSRF guard.
	AllowPrivateAddressesForTests bool
}

// NewGuardedClient builds an http.Client that will not connect to private,
// loopback, link-local or reserved addresses, follows at most MaxRedirects
// hops, and re-validates every hop.
//
// The address check lives in Dialer.Control, which runs after DNS resolution
// and immediately before connect. That placement is what makes it robust: it
// sees the address actually being dialled, so DNS rebinding, multi-record
// hosts and redirect chains are all covered without extra bookkeeping.
// CheckRedirect adds the two things Control cannot see — the next hop's
// scheme, and how many hops have happened.
func NewGuardedClient(opts ClientOptions) *http.Client {
	maxRedirects := opts.MaxRedirects
	if maxRedirects <= 0 {
		maxRedirects = DefaultMaxRedirects
	}
	timeout := opts.Timeout
	if timeout <= 0 {
		timeout = DefaultFetchTimeout
	}

	dialer := &net.Dialer{
		Timeout:   30 * time.Second,
		KeepAlive: 30 * time.Second,
		Control: func(_, address string, _ syscall.RawConn) error {
			if opts.AllowPrivateAddressesForTests {
				return nil
			}
			return CheckDialAddress(address)
		},
	}

	transport := &http.Transport{
		DialContext:           dialer.DialContext,
		TLSHandshakeTimeout:   15 * time.Second,
		ResponseHeaderTimeout: 60 * time.Second,
		ExpectContinueTimeout: 5 * time.Second,
		MaxIdleConns:          8,
		IdleConnTimeout:       30 * time.Second,
	}

	return &http.Client{
		Timeout:   timeout,
		Transport: transport,
		CheckRedirect: func(req *http.Request, via []*http.Request) error {
			if len(via) >= maxRedirects {
				return fmt.Errorf("%w: stopped after %d hops", ErrTooManyRedirects, len(via))
			}
			switch strings.ToLower(req.URL.Scheme) {
			case "http", "https":
			default:
				return fmt.Errorf("%w: redirect to scheme %q", ErrUnsupportedSource, req.URL.Scheme)
			}
			// When the redirect target is a bare IP, reject it here so the
			// error names the redirect rather than surfacing as a dial
			// failure. Hostname targets are still caught by Control.
			if !opts.AllowPrivateAddressesForTests {
				if addr, err := netip.ParseAddr(req.URL.Hostname()); err == nil && IsBlockedAddr(addr) {
					return fmt.Errorf("%w: redirect to %s", ErrBlockedAddress, addr)
				}
			}
			return nil
		},
	}
}
```

```go
package ingest

import (
	"errors"
	"fmt"
)

// ErrNotEnoughDisk means an acquisition was refused before it started.
var ErrNotEnoughDisk = errors.New("ingest: not enough free disk space")

// DefaultDiskHeadroom is kept free beyond whatever a download needs, so a
// large ingest cannot wedge SQLite or the thumbnailer.
const DefaultDiskHeadroom = 1 << 30 // 1 GiB

// FreeSpaceFunc reports the bytes available on the filesystem holding path.
type FreeSpaceFunc func(path string) (uint64, error)

// CheckFreeSpace refuses an acquisition that would leave less than headroom
// free. A filesystem that cannot report its free space is not an error:
// ingestion proceeds rather than being blocked by a missing measurement.
func CheckFreeSpace(free FreeSpaceFunc, path string, need, headroom uint64) error {
	if free == nil {
		return nil
	}
	available, err := free(path)
	if err != nil {
		return nil // unknown; proceed
	}
	required := need + headroom
	if available < required {
		return fmt.Errorf("%w: %d bytes free on %s, need %d (%d for the download plus %d headroom)",
			ErrNotEnoughDisk, available, path, required, need, headroom)
	}
	return nil
}
```

```go
package ingest

import (
	"context"
	"errors"
	"fmt"
	"io"
	"mime"
	"net/http"
	"net/url"
	"os"
	"path"
	"strings"

	"boobies-media/internal/media"
)

// Fetch failures that callers translate into friendly job errors.
var (
	ErrDownloadTooLarge = errors.New("ingest: the download is larger than the limit")
	ErrBadStatus        = errors.New("ingest: the server refused the request")
)

// Fetcher downloads a single URL into a scratch file.
type Fetcher struct {
	Client       *http.Client
	TmpDir       string
	FreeSpace    FreeSpaceFunc
	DiskHeadroom uint64
}

// NewFetcher builds a Fetcher with the SSRF-guarded client.
func NewFetcher(tmpDir string, opts ClientOptions) *Fetcher {
	return &Fetcher{
		Client:       NewGuardedClient(opts),
		TmpDir:       tmpDir,
		FreeSpace:    FreeSpace,
		DiskHeadroom: DefaultDiskHeadroom,
	}
}

// FetchResult is a downloaded file waiting to be handed to media.Store.Save.
type FetchResult struct {
	Path     string
	Size     int64
	Filename string
}

// Fetch downloads rawURL to a scratch file, refusing anything over maxBytes.
// The caller owns the returned file and must remove it.
func (f *Fetcher) Fetch(ctx context.Context, rawURL string, maxBytes int64) (*FetchResult, error) {
	if maxBytes <= 0 {
		return nil, fmt.Errorf("ingest: download cap must be positive, got %d", maxBytes)
	}
	// Refuse before a byte moves if the disk is already tight.
	if err := CheckFreeSpace(f.FreeSpace, f.TmpDir, uint64(maxBytes), f.DiskHeadroom); err != nil {
		return nil, err
	}

	req, err := http.NewRequestWithContext(ctx, http.MethodGet, rawURL, nil)
	if err != nil {
		return nil, fmt.Errorf("%w: %v", ErrUnsupportedSource, err)
	}
	// Some CDNs (Discord included) serve differently or not at all without a
	// plausible user agent.
	req.Header.Set("User-Agent", userAgent)
	req.Header.Set("Accept", "*/*")

	resp, err := f.Client.Do(req)
	if err != nil {
		return nil, err // already wrapped: ErrBlockedAddress, ErrTooManyRedirects, context errors
	}
	defer resp.Body.Close()

	if resp.StatusCode < 200 || resp.StatusCode > 299 {
		return nil, fmt.Errorf("%w: HTTP %d", ErrBadStatus, resp.StatusCode)
	}
	// An announced oversize body is refused before it is streamed. This is a
	// courtesy check: the limited reader below is the real enforcement,
	// because Content-Length can be absent or simply wrong.
	if resp.ContentLength > 0 && resp.ContentLength > maxBytes {
		return nil, fmt.Errorf("%w: the server announced %d bytes, limit is %d",
			ErrDownloadTooLarge, resp.ContentLength, maxBytes)
	}

	tmp, err := os.CreateTemp(f.TmpDir, "fetch-*")
	if err != nil {
		return nil, fmt.Errorf("ingest: create scratch file: %w", err)
	}
	tmpPath := tmp.Name()
	cleanup := func() {
		_ = tmp.Close()
		_ = os.Remove(tmpPath)
	}

	// Read one byte past the cap so exceeding it is detectable.
	written, copyErr := io.Copy(tmp, io.LimitReader(resp.Body, maxBytes+1))
	if copyErr != nil {
		cleanup()
		return nil, fmt.Errorf("ingest: download failed: %w", copyErr)
	}
	if written > maxBytes {
		cleanup()
		return nil, fmt.Errorf("%w: stopped after %d bytes, limit is %d", ErrDownloadTooLarge, written, maxBytes)
	}
	if err := tmp.Close(); err != nil {
		_ = os.Remove(tmpPath)
		return nil, fmt.Errorf("ingest: close scratch file: %w", err)
	}

	return &FetchResult{
		Path:     tmpPath,
		Size:     written,
		Filename: filenameFor(rawURL, resp.Header.Get("Content-Disposition")),
	}, nil
}

// userAgent is sent on every direct fetch.
const userAgent = "boobies-media/1.0 (+self-hosted media server)"

// filenameFor derives a display filename, preferring Content-Disposition and
// falling back to the URL path. The result is always sanitised, because it
// eventually reaches a Content-Disposition header of our own.
func filenameFor(rawURL, contentDisposition string) string {
	if contentDisposition != "" {
		if _, params, err := mime.ParseMediaType(contentDisposition); err == nil {
			if name := strings.TrimSpace(params["filename"]); name != "" {
				return media.SanitizeFilename(name)
			}
		}
	}
	if parsed, err := url.Parse(rawURL); err == nil {
		if base := path.Base(parsed.Path); base != "" && base != "/" && base != "." {
			return media.SanitizeFilename(base)
		}
	}
	return "download"
}
```

```go
package ingest

import (
	"context"
	"fmt"
	"os"
	"path/filepath"
	"strings"
)

// SettingsReader is the slice of db.Store this package needs. Keeping it an
// interface means the cookie logic is testable without a database.
type SettingsReader interface {
	SettingGet(ctx context.Context, key string) (string, error)
}

// CookieSettingKey is the settings key holding an extractor's cookie path.
func CookieSettingKey(extractor string) string {
	return "cookies_" + extractor
}

// ResolveCookieFile finds the cookie file to pass as --cookies, or "" when
// there is none.
//
// Order: the configured path, then the conventional data/cookies/<name>.txt,
// then nothing. A configured path that does not exist is an error rather than
// a silent fallback — an admin who typed a path wants to know it is wrong,
// and a silently ignored setting is exactly how "X stopped working" turns
// into an unexplained mystery.
func ResolveCookieFile(ctx context.Context, settings SettingsReader, cookiesDir, extractor string) (string, error) {
	if !isKnownExtractor(extractor) {
		return "", fmt.Errorf("ingest: unknown extractor %q", extractor)
	}

	if settings != nil {
		configured, err := settings.SettingGet(ctx, CookieSettingKey(extractor))
		if err != nil {
			return "", fmt.Errorf("ingest: read cookie setting for %s: %w", extractor, err)
		}
		if configured = strings.TrimSpace(configured); configured != "" {
			if err := checkCookieFile(configured); err != nil {
				return "", fmt.Errorf("ingest: the configured %s cookie file is unusable: %w", extractor, err)
			}
			return configured, nil
		}
	}

	conventional := filepath.Join(cookiesDir, extractor+".txt")
	if err := checkCookieFile(conventional); err == nil {
		return conventional, nil
	}
	return "", nil
}

func checkCookieFile(path string) error {
	info, err := os.Stat(path)
	if err != nil {
		return err
	}
	if info.IsDir() {
		return fmt.Errorf("%s is a directory, not a cookie file", path)
	}
	return nil
}

func isKnownExtractor(extractor string) bool {
	for _, known := range Extractors {
		if known == extractor {
			return true
		}
	}
	return false
}
```

**Output collection is by directory, not by parsing stdout.** Each rip gets a fresh scratch directory; afterwards the directory is listed. That is immune to yt-dlp's output format changing between releases — which it does — and works identically for `gallery-dl`.

**`--max-filesize` does not always fail.** yt-dlp often prints "File is larger than max-filesize. Aborting" and exits **zero**, leaving nothing behind. An empty result directory must therefore be inspected against the tool output before being reported, or "video too large" surfaces as the useless "nothing was downloaded".

```go
package ingest

import (
	"context"
	"errors"
	"fmt"
	"os"
	"path/filepath"
	"sort"
	"strconv"
	"strings"

	"boobies-media/internal/media"
)

// Rip failures that the handler turns into friendly job errors.
var (
	ErrNeedsCookies      = errors.New("ingest: this source needs an exported cookie file")
	ErrNothingDownloaded = errors.New("ingest: nothing was downloaded")
)

// partialSuffixes are scratch files a tool may leave beside real output.
var partialSuffixes = []string{".part", ".ytdl", ".temp", ".tmp"}

// Ripper drives yt-dlp and gallery-dl.
type Ripper struct {
	Runner media.Runner
	TmpDir string
}

// NewRipper builds a Ripper writing scratch directories under tmpDir.
func NewRipper(runner media.Runner, tmpDir string) *Ripper {
	return &Ripper{Runner: runner, TmpDir: tmpDir}
}

// RipRequest describes one download.
type RipRequest struct {
	URL        string
	Extractor  string
	Format     string // yt-dlp format selector; empty uses the tool default
	CookieFile string // "" means run without cookies
	MaxBytes   int64
}

// RipResult is a scratch directory of downloaded files. The caller owns Dir
// and must remove it.
type RipResult struct {
	Dir   string
	Files []string
	Tool  string
}

// RipWithYtDlp downloads a URL into a fresh scratch directory.
//
// Output is collected by listing that directory rather than by parsing the
// tool's stdout: yt-dlp's output format changes between releases, a directory
// listing does not, and the same approach works unchanged for gallery-dl.
func (r *Ripper) RipWithYtDlp(ctx context.Context, req RipRequest) (*RipResult, error) {
	dir, err := os.MkdirTemp(r.TmpDir, "ytdlp-*")
	if err != nil {
		return nil, fmt.Errorf("ingest: create rip directory: %w", err)
	}

	args := []string{
		"--no-playlist",   // a channel or playlist URL must not pull hundreds of videos
		"--no-progress",
		"--no-warnings",
		"--no-part",       // write final names directly, so the listing is clean
		"--restrict-filenames",
		"--merge-output-format", "mp4",
	}
	if req.Format != "" {
		args = append(args, "-f", req.Format)
	}
	if req.MaxBytes > 0 {
		args = append(args, "--max-filesize", strconv.FormatInt(req.MaxBytes, 10))
	}
	if req.CookieFile != "" {
		args = append(args, "--cookies", req.CookieFile)
	}
	args = append(args,
		"-o", filepath.Join(dir, "%(id)s.%(ext)s"),
		"--", req.URL, // "--" so a URL starting with "-" can never become a flag
	)

	output, runErr := r.Runner.Run(ctx, "yt-dlp", args...)
	if runErr != nil {
		_ = os.RemoveAll(dir)
		if errors.Is(runErr, media.ErrToolMissing) {
			return nil, fmt.Errorf("%w — install yt-dlp to ingest links from %s",
				runErr, req.Extractor)
		}
		return nil, TranslateToolError("yt-dlp", runErr, string(output))
	}

	files, err := collectOutputFiles(dir)
	if err != nil {
		_ = os.RemoveAll(dir)
		return nil, err
	}
	if len(files) == 0 {
		_ = os.RemoveAll(dir)
		// yt-dlp frequently reports an oversize abort on stdout and still
		// exits zero, so an empty directory has to be interpreted against the
		// tool output or "too large" surfaces as "nothing was downloaded".
		return nil, TranslateToolError("yt-dlp", ErrNothingDownloaded, string(output))
	}
	return &RipResult{Dir: dir, Files: files, Tool: "yt-dlp"}, nil
}

// collectOutputFiles lists the real (non-scratch, non-empty) files a tool
// produced, sorted so item ordering is deterministic.
func collectOutputFiles(dir string) ([]string, error) {
	var files []string
	err := filepath.WalkDir(dir, func(path string, entry os.DirEntry, err error) error {
		if err != nil {
			return err
		}
		if entry.IsDir() {
			return nil
		}
		name := entry.Name()
		for _, suffix := range partialSuffixes {
			if strings.HasSuffix(name, suffix) {
				return nil
			}
		}
		info, err := entry.Info()
		if err != nil {
			return err
		}
		if info.Size() == 0 {
			return nil
		}
		files = append(files, path)
		return nil
	})
	if err != nil {
		return nil, fmt.Errorf("ingest: list downloaded files: %w", err)
	}
	sort.Strings(files)
	return files, nil
}

// TranslateToolError turns a tool's output into an error a friend can act on.
// It always returns a non-nil error.
//
// The generic case still carries the tool's own message, because when the
// cause is genuinely novel the raw text is the most useful thing available.
func TranslateToolError(tool string, cause error, output string) error {
	lowered := strings.ToLower(output)

	switch {
	case strings.Contains(lowered, "max-filesize"), strings.Contains(lowered, "larger than"):
		return fmt.Errorf("%w: %s stopped because the file is too large", ErrDownloadTooLarge, tool)

	case strings.Contains(lowered, "--cookies"),
		strings.Contains(lowered, "sign in"),
		strings.Contains(lowered, "log in"),
		strings.Contains(lowered, "login"),
		strings.Contains(lowered, "requires authentication"),
		strings.Contains(lowered, "private video"),
		strings.Contains(lowered, "age-restricted"):
		return fmt.Errorf("%w: %s could not access this without an exported cookie file — "+
			"add one under data/cookies and set its path in admin settings", ErrNeedsCookies, tool)

	case strings.Contains(lowered, "unsupported url"),
		strings.Contains(lowered, "no video formats found"),
		strings.Contains(lowered, "unable to extract"):
		return fmt.Errorf("%w: %s does not know how to download this link", ErrUnsupportedSource, tool)
	}

	detail := firstMeaningfulLine(output)
	if detail == "" {
		detail = cause.Error()
	}
	return fmt.Errorf("ingest: %s failed: %s", tool, detail)
}

// firstMeaningfulLine picks the most informative line of tool output, which is
// usually the first one starting with ERROR.
func firstMeaningfulLine(output string) string {
	lines := strings.Split(output, "\n")
	for _, line := range lines {
		trimmed := strings.TrimSpace(line)
		if strings.HasPrefix(trimmed, "ERROR") {
			return trimmed
		}
	}
	for _, line := range lines {
		if trimmed := strings.TrimSpace(line); trimmed != "" {
			return trimmed
		}
	}
	return ""
}
```

```go
package ingest

import (
	"context"
	"errors"
	"fmt"
	"os"

	"boobies-media/internal/media"
)

// GalleryFallbackExtractors are the sources where a yt-dlp failure is worth
// retrying with gallery-dl. Only Twitter qualifies: yt-dlp handles video
// there, but an image-only post has no video stream for it to find.
var GalleryFallbackExtractors = []string{"twitter"}

// RipWithGalleryDL downloads an image gallery into a fresh scratch directory.
func (r *Ripper) RipWithGalleryDL(ctx context.Context, req RipRequest) (*RipResult, error) {
	dir, err := os.MkdirTemp(r.TmpDir, "gallerydl-*")
	if err != nil {
		return nil, fmt.Errorf("ingest: create rip directory: %w", err)
	}

	args := []string{"-D", dir, "--no-mtime"}
	if req.CookieFile != "" {
		args = append(args, "--cookies", req.CookieFile)
	}
	args = append(args, "--", req.URL)

	output, runErr := r.Runner.Run(ctx, "gallery-dl", args...)
	if runErr != nil {
		_ = os.RemoveAll(dir)
		if errors.Is(runErr, media.ErrToolMissing) {
			return nil, fmt.Errorf("%w — install gallery-dl to ingest image galleries", runErr)
		}
		return nil, TranslateToolError("gallery-dl", runErr, string(output))
	}

	files, err := collectOutputFiles(dir)
	if err != nil {
		_ = os.RemoveAll(dir)
		return nil, err
	}
	if len(files) == 0 {
		_ = os.RemoveAll(dir)
		return nil, TranslateToolError("gallery-dl", ErrNothingDownloaded, string(output))
	}
	return &RipResult{Dir: dir, Files: files, Tool: "gallery-dl"}, nil
}

// Rip downloads a URL with yt-dlp, falling back to gallery-dl where that is
// likely to help.
//
// The fallback is deliberately narrow. It runs only for Twitter, and only when
// yt-dlp failed in a way that means "there was no video here" — not when the
// failure was about cookies (gallery-dl needs the same ones), size (the file
// is still too big), or transport (the network is still down). Retrying those
// doubles the wait and replaces a precise error with a vaguer one.
func (r *Ripper) Rip(ctx context.Context, req RipRequest) (*RipResult, error) {
	result, err := r.RipWithYtDlp(ctx, req)
	if err == nil {
		return result, nil
	}
	if !shouldTryGallery(req.Extractor, err) {
		return nil, err
	}

	fallbackResult, fallbackErr := r.RipWithGalleryDL(ctx, req)
	if fallbackErr == nil {
		return fallbackResult, nil
	}
	// Name both attempts: "yt-dlp found no video and gallery-dl is missing"
	// is a far more actionable message than either half alone.
	return nil, fmt.Errorf("%v; the gallery-dl fallback also failed: %w", err, fallbackErr)
}

func shouldTryGallery(extractor string, ytDlpErr error) bool {
	eligible := false
	for _, candidate := range GalleryFallbackExtractors {
		if candidate == extractor {
			eligible = true
			break
		}
	}
	if !eligible {
		return false
	}
	switch {
	case errors.Is(ytDlpErr, ErrNeedsCookies):
		return false // gallery-dl needs the same cookies
	case errors.Is(ytDlpErr, ErrDownloadTooLarge):
		return false // still too large
	case errors.Is(ytDlpErr, media.ErrToolMissing):
		return true // yt-dlp is not installed; gallery-dl might be
	case errors.Is(ytDlpErr, ErrUnsupportedSource):
		return true // "no video formats found" — exactly the gallery case
	case errors.Is(ytDlpErr, ErrNothingDownloaded):
		return true
	}
	return false
}
```

- Produces:
  - `ingest.URLJob` struct: `URL string` (json `url`), `UploaderID int64` (json `uploader_id`) — the `ingest_url` job payload
  - `ingest.Saver` interface: `Save(ctx context.Context, req media.SaveRequest) (*media.SaveResult, error)`
  - `ingest.Ingestor` struct: `Settings SettingsReader`, `Media Saver`, `Fetcher *Fetcher`, `Ripper *Ripper`, `CookiesDir string`, `TmpDir string`, `FreeSpace FreeSpaceFunc`
  - `ingest.NewIngestor(cfg *config.Config, settings SettingsReader, saver Saver) *Ingestor`
  - `(*Ingestor) Handle(ctx context.Context, job db.Job) error` — matches `jobs.Handler` structurally, so this package never imports `internal/jobs`

**Three calls worth stating.** First, every `Save` here passes `MaxBytes` explicitly: `SaveRequest.MaxBytes` *overrides the `upload_max_bytes` setting when positive*, and without it a 2 GiB video rip would be judged against the browser upload cap rather than the download cap that actually governs a rip. Second, when a rip yields several files, ones the allowlist rejects (subtitles, `.description` files) are skipped quietly as long as at least one real media file survives — a gallery should not fail because yt-dlp also wrote a text file. Zero survivors is an error. Third, handler errors are the strings friends read in the UI, and the queue retries them up to `jobs.MaxAttempts`; the messages built in Tasks 5–8 are already actionable, so `Handle` passes them through instead of re-wording them.

The handler does one `CheckFreeSpace` itself using the `min_free_disk_bytes` setting; `Fetch` will check again with its built-in default headroom, which is harmless — the handler's check is the one an admin can tune.

```go
// enqueue time; Handle unmarshals it here.
type URLJob struct {
	URL        string `json:"url"`

// Saver is the slice of media.Store this package needs. Every acquired byte
// goes through it — ingest never writes to files/ and never sniffs a mime.
type Saver interface {
	Save(ctx context.Context, req media.SaveRequest) (*media.SaveResult, error)
}

// defaultDownloadCap mirrors db.DefaultSettings["download_max_bytes"]. It is
// reached only if an admin writes something unparseable into the setting.
const defaultDownloadCap = 2 << 30 // 2 GiB

// Ingestor turns a pasted URL into one or more library items. It is
// constructed once at startup and shared by every worker, so its fields are
// never mutated after NewIngestor.
type Ingestor struct {
	Settings   SettingsReader
	Media      Saver
	Fetcher    *Fetcher
	Ripper     *Ripper
	CookiesDir string
	TmpDir     string
	FreeSpace  FreeSpaceFunc
}

// NewIngestor wires an Ingestor from the real config, settings store and
// media store. Tests replace Fetcher and FreeSpace after construction.
func NewIngestor(cfg *config.Config, settings SettingsReader, saver Saver) *Ingestor {
	return &Ingestor{
		Settings:   settings,
		Media:      saver,
		Fetcher:    NewFetcher(cfg.TmpDir(), ClientOptions{}),
		Ripper:     NewRipper(media.NewExecRunner(), cfg.TmpDir()),
		CookiesDir: cfg.CookiesDir(),
		TmpDir:     cfg.TmpDir(),
		FreeSpace:  FreeSpace,
	}
}

// Handle is the jobs.Handler for ingest_url. Its error strings surface
// verbatim in the UI's job list, so they are written for a friend, not a log.
func (i *Ingestor) Handle(ctx context.Context, job db.Job) error {
	var payload URLJob
	if err := json.Unmarshal(job.Payload, &payload); err != nil {
		return fmt.Errorf("ingest: job payload is not valid JSON: %w", err)
	}
	if payload.UploaderID == 0 {
		return errors.New("ingest: job payload has no uploader")
	}

	classification, err := Classify(payload.URL)
	if err != nil {
		return err
	}

	maxBytes := i.settingInt64(ctx, "download_max_bytes", defaultDownloadCap)
	headroom := uint64(i.settingInt64(ctx, "min_free_disk_bytes", DefaultDiskHeadroom))
	if err := CheckFreeSpace(i.FreeSpace, i.TmpDir, uint64(maxBytes), headroom); err != nil {
		return err
	}

	switch classification.Kind {
	case KindDirect, KindDiscordCDN:
		return i.fetchOne(ctx, job, payload, classification, maxBytes)
	case KindYtDlp:
		return i.rip(ctx, job, payload, classification, maxBytes)
	default:
		return fmt.Errorf("%w: %s", ErrUnsupportedSource, payload.URL)
	}
}

// fetchOne downloads a direct or Discord CDN URL and saves the single file.
func (i *Ingestor) fetchOne(ctx context.Context, job db.Job, payload URLJob, c Classification, maxBytes int64) error {
	res, err := i.Fetcher.Fetch(ctx, c.URL, maxBytes)
	if err != nil {
		return err
	}
	defer os.Remove(res.Path)

	file, err := os.Open(res.Path)
	if err != nil {
		return fmt.Errorf("ingest: reopen download: %w", err)
	}
	defer file.Close()

	// MaxBytes must be set: SaveRequest.MaxBytes overrides the (smaller)
	// upload_max_bytes setting, which applies to browser uploads, not rips.
	_, err = i.Media.Save(ctx, media.SaveRequest{
		Reader:     file,
		Filename:   res.Filename,
		UploaderID: payload.UploaderID,
		SourceURL:  c.URL,
		JobID:      job.ID,
		MaxBytes:   maxBytes,
	})
	if errors.Is(err, media.ErrUnsupportedType) {
		return fmt.Errorf("the link downloaded, but it is not a supported image or video: %w", err)
	}
	return err
}

// rip runs yt-dlp (with the gallery-dl fallback) and saves every media file
// it produced. Non-media by-products are skipped as long as real media
// survives; zero survivors is a failure.
func (i *Ingestor) rip(ctx context.Context, job db.Job, payload URLJob, c Classification, maxBytes int64) error {
	format, err := i.Settings.SettingGet(ctx, "ytdlp_format")
	if err != nil {
		return fmt.Errorf("ingest: read ytdlp_format: %w", err)
	}
	cookieFile, err := ResolveCookieFile(ctx, i.Settings, i.CookiesDir, c.Extractor)
	if err != nil {
		return err
	}

	res, err := i.Ripper.Rip(ctx, RipRequest{
		URL:        c.URL,
		Extractor:  c.Extractor,
		Format:     format,
		CookieFile: cookieFile,
		MaxBytes:   maxBytes,
	})
	if err != nil {
		return err
	}
	defer os.RemoveAll(res.Dir)

	saved := 0
	for _, path := range res.Files {
		file, err := os.Open(path)
		if err != nil {
			return fmt.Errorf("ingest: open ripped file: %w", err)
		}
		_, err = i.Media.Save(ctx, media.SaveRequest{
			Reader:     file,
			Filename:   filepath.Base(path),
			UploaderID: payload.UploaderID,
			SourceURL:  c.URL,
			JobID:      job.ID,
			MaxBytes:   maxBytes,
		})
		file.Close()
		if errors.Is(err, media.ErrUnsupportedType) {
			continue
		}
		if err != nil {
			return err
		}
		saved++
	}
	if saved == 0 {
		return fmt.Errorf("%s downloaded %d file(s), but none of them is a supported image or video",
			res.Tool, len(res.Files))
	}
	return nil
}

// settingInt64 reads a numeric setting, falling back on garbage. Settings
// have code-side defaults, so an error here means a broken override.
func (i *Ingestor) settingInt64(ctx context.Context, key string, fallback int64) int64 {
	raw, err := i.Settings.SettingGet(ctx, key)
	if err != nil {
		return fallback
	}
	n, err := strconv.ParseInt(strings.TrimSpace(raw), 10, 64)
	if err != nil || n <= 0 {
		return fallback
	}
	return n
}
```

```go
// handleIngestURL accepts POST /api/ingest with a JSON body {"url": "…"}.
// The response is a job, not an item — an item cannot exist before the
// download completes and its hash is known. Callers poll GET /api/jobs/{id},
// which returns the resulting items when the job is done.
func (s *Server) handleIngestURL(w http.ResponseWriter, r *http.Request, user *db.User) {
	if !s.requireQueue(w, r) {
		return
	}
	var body struct {
		URL string `json:"url"`
	}
	if err := json.NewDecoder(io.LimitReader(r.Body, 1<<16)).Decode(&body); err != nil {
		writeJSONError(w, http.StatusBadRequest, "bad_request", `expected a JSON body like {"url": "https://…"}`)
		return
	}
	classification, err := ingest.Classify(body.URL)
	if err != nil {
		// Fail at submit time, not inside a job the user has to go read.
		writeJSONError(w, http.StatusBadRequest, "unsupported_url",
			"only http and https links can be ingested")
		return
	}
	jobID, err := s.Queue.Enqueue(r.Context(), jobs.TypeIngestURL, ingest.URLJob{
		URL:        classification.URL,
		UploaderID: user.ID,
	})
	if err != nil {
		s.serverError(w, r, err)
		return
	}
	writeJSON(w, http.StatusAccepted, map[string]any{
		"job_id": jobID,
		"status": "queued",
		"kind":   classification.Kind.String(),
	})
}

// requireQueue guards routes that need the job queue, mirroring requireMedia.
func (s *Server) requireQueue(w http.ResponseWriter, r *http.Request) bool {
	if s.Queue == nil {
		writeJSONError(w, http.StatusServiceUnavailable, "queue_unavailable", "the job queue is not running")
		return false
	}
	return true
}
```

```ts
  const POLL_INTERVAL_MS = 2000;
  const POLL_DEADLINE_MS = 10 * 60 * 1000; // a 2 GiB rip on home upstream is slow

  interface JobStatus {
    status: string;
    error: string;
    items: ApiItem[];
  }

  function sleep(ms: number): Promise<void> {
    return new Promise((resolve) => window.setTimeout(resolve, ms));
  }

  function shortName(url: string): string {
    try {
      const parsed = new URL(url);
      const path = parsed.pathname.length > 24 ? `${parsed.pathname.slice(0, 24)}…` : parsed.pathname;
      return parsed.hostname + path;
    } catch {
      return url.slice(0, 40);
    }
  }

  async function ingestURL(url: string): Promise<void> {
    const row = document.createElement("li");
    row.className = "uploads__row";
    row.textContent = `${shortName(url)} — submitting…`;
    list!.appendChild(row);

    try {
      const response = await fetch("/api/ingest", {
        method: "POST",
        headers: { "Content-Type": "application/json" },
        body: JSON.stringify({ url }),
      });
      if (!response.ok) {
        const detail = (await response.json().catch(() => null)) as IngestError | null;
        row.textContent = `${shortName(url)} — ${detail?.error ?? `failed (${response.status})`}`;
        row.classList.add("uploads__row--error");
        return;
      }
      const accepted = (await response.json()) as { job_id: number };
      await pollJob(accepted.job_id, url, row);
    } catch (err) {
      console.error(err);
      row.textContent = `${shortName(url)} — the request failed`;
      row.classList.add("uploads__row--error");
    }
  }

  async function pollJob(jobID: number, url: string, row: HTMLElement): Promise<void> {
    const deadline = Date.now() + POLL_DEADLINE_MS;
    row.textContent = `${shortName(url)} — downloading…`;
    while (Date.now() < deadline) {
      await sleep(POLL_INTERVAL_MS);
      const response = await fetch(`/api/jobs/${jobID}`, { headers: { Accept: "application/json" } });
      if (!response.ok) continue; // transient; keep polling until the deadline
      const job = (await response.json()) as JobStatus;
      if (job.status === "done") {
        grid?.querySelector('[data-role="empty"]')?.remove();
        for (const item of [...job.items].reverse()) grid?.prepend(renderTile(item));
        const n = job.items.length;
        row.textContent = `${shortName(url)} — done (${n} item${n === 1 ? "" : "s"})`;
        row.classList.add("uploads__row--done");
        window.setTimeout(() => row.remove(), 4000);
        return;
      }
      if (job.status === "failed") {
        // Task 9 wrote these error strings for humans; show them verbatim.
        row.textContent = `${shortName(url)} — ${job.error || "failed"}`;
        row.classList.add("uploads__row--error");
        return;
      }
      if (job.error) {
        row.textContent = `${shortName(url)} — retrying: ${job.error}`;
      }
    }
    row.textContent = `${shortName(url)} — still working; check the admin page later`;
  }
```

## Definition of Done

- [ ] `go test ./... -race -count=1` passes; no test reaches the network (every fixture is `httptest`, every tool a stub).
- [ ] `bunx tsc --noEmit` is clean and `web/static/dist/main.js` stays under 50 KB.
